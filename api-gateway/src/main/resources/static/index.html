Visão do Sistema

Online

A arquitetura distribuída conecta o navegador com o API Gateway (Spring Boot :8080), que valida os payloads e faz chamadas RPC tipadas com deadline aos 3 microsserviços internos via gRPC/HTTP2 com persistência real em PostgreSQL.

API Gateway (Borda REST + JWT) Porta 8080
Microsserviço Alunos (gRPC) Porta 9091
Microsserviço Treinos (gRPC) Porta 9092
Microsserviço Financeiro (gRPC) Porta 9093

Validação Bean Validation
